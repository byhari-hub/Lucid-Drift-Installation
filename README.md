# Lucid-Drift-Installation  
### Lucid Drift: Where memory wakes in fragments

Lucid Drift is an ongoing experimental research installation exploring memory, fragmentation, and reconstruction. Situated within the conceptual frame of *Orphaned Archives*, the project interrogates authorship, ownership, and the persistence of memory beyond centralized digital systems.

It operates on a core contradiction:

> An archive can be formally complete and still fail to preserve what it was meant to hold.

This is not about loss through decay, neglect, or technological failure.  
It is about the structural inadequacy of formal capture itself.

---

## Conceptual Framework

Lucid Drift uses inherited material — specifically a composer's archive — as both source and site of investigation. The archive is not treated as a memorial object, but as an operational system under stress.

Rather than extending archival preservation logics, the project exposes their failure modes. Computational design is used not to stabilise memory, but to make its instability perceptible.

The work stages the gap between:
- what an archive records  
- and what an inheritor actually receives

Lucid Drift does not attempt to reconstruct a “true” memory.  
It maps the friction between documentation and lived inheritance.

## Technical Approach

The installation uses generative and real-time systems to translate archival fragments into unstable audiovisual forms. The computational layer functions as an interpretive failure engine rather than a preservation tool.
